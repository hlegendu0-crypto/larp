# LarpBattle

Платформа live 1v1 видео-баттлов: игроки показывают в камеру свои вещи, AI распознаёт предметы и оценивает их рыночную стоимость. Побеждает больший **Flex Score**. Победы двигают ELO-рейтинг и ранги.

**Текущий статус: Этап 2 — реальный AI-пайплайн (соло-режим) поверх кликабельного прототипа.**

## Что реализовано (этап 1)

- **Лендинг** — хиро, live-счётчик онлайна, «Как это работает», топ-5 лидерборда, футер (правила / ToS / Privacy / 18+)
- **Авторизация** — заглушка: вход по нику + подтверждение 18+ (email/OAuth — этап 4)
- **Camera Check** — реальная камера через `getUserMedia`, индикаторы освещения/фрейминга, подсказки
- **Лобби** — «Быстрый матч» (симуляция очереди, ELO ±150 с расширением) и «Вызов друга» (инвайт-ссылка, демо-вход)
- **Экран баттла** — заставка VS → отсчёт 3-2-1 → раунд 60 сек: своя камера реальная (PiP, переключаемо), соперник — симуляция, live-лента распознаваний, анимированные Flex Score c «перетягиванием» лидерства, челлендж-оверлеи, сдаться/репорт/выход
- **Результаты** — «Идёт подсчёт…», победитель, разбивка по айтемам с причинами незачёта, дельта ELO, реванш/новый матч/поделиться
- **Лидерборд** — топ по ELO с закреплённой строкой своей позиции
- **Профиль** — ELO, ранг, винрейт, история матчей, самый дорогой айтем
- **Настройки** — ник, устройства, удаление аккаунта; страницы правил, ToS, Privacy

Прогресс игрока хранится в `localStorage`.

## Что реализовано (этап 2) — режим «Оцени мой флекс»

Реальный AI-пайплайн оценки по ТЗ §7.1–7.3, соло-раунд без соперника (вход из лобби):

- **Захват кадров** (`src/lib/capture.js`, `phash.js`) — тик каждые 500 мс, перцептивный
  хэш dHash 256 бит; на анализ уходит кадр только когда картинка стабильна ~1 с **и**
  сцена отличается от последней проанализированной. Лимит 15 кадров на раунд +
  минимальный интервал 2,5 с — контроль стоимости (ТЗ §11).
- **Vision-анализ** (`src/lib/vision.js`) — Claude API из браузера (официальный SDK),
  строгий JSON через structured outputs: `items[{name, category, est_price_usd,
  confidence, is_screen_or_photo}]`, `nsfw`. Промпт версионируется (`flex-appraiser-v1`).
- **Подсчёт** — дедуп по нормализованному названию, порог `confidence ≥ 0.5`,
  `is_screen_or_photo` → страйк (3 страйка = дисквалификация), `nsfw` → мгновенная
  остановка раунда.
- **Настройки AI** — API-ключ (хранится в localStorage браузера) и выбор модели:
  Opus 4.8 (по умолчанию, максимум качества) / Sonnet 5 / Haiku 4.5 (укладывается
  в NFR ≤ $0.10 за раунд).

## Запуск

```bash
npm install
cp .env.example .env.local   # подставьте свой ключ Anthropic (или введите его в настройках приложения)
npm run dev                  # http://localhost:5173
npm run build                # прод-сборка в dist/
```

⚠️ `VITE_ANTHROPIC_API_KEY` из `.env.local` запекается в JS-бандл при сборке — это
удобно для локальной разработки, но такую сборку нельзя выкладывать публично.
Для деплоя оставьте переменную пустой: игроки вводят собственный ключ в настройках.
На этапе 4 вызовы AI переезжают на бэкенд.

## Стек

React 18 + Vite + Tailwind CSS 4, React Router (hash-роутинг — деплой на любую статику),
`@anthropic-ai/sdk` (vision, structured outputs). Без бэкенда.

## Дорожная карта (по ТЗ)

| Этап | Содержание |
|---|---|
| **1. UI с заглушками** ✅ | Все экраны, мок-данные, демо-баттл |
| **2. Реальный AI (соло)** ✅ | Захват кадров + pHash, Claude API (vision), режим «оцени мой флекс» |
| 3. Live 1v1 | WebRTC, матчмейкинг, приватные комнаты, синхронизация счёта |
| 4. Прод-обвязка | Аккаунты, ELO/лидерборд на бэке, античит-база, модерация |

Ключевые структуры под будущие этапы: формат айтема повторяет JSON-контракт vision-модели (`name`, `category`, `est_price_usd`, `confidence`, флаги незачёта), ELO/ранги — в `src/lib/elo.js`, параметры раунда и скрипт демо-баттла — в `src/data/mock.js`.
